# TapTap — 배포

만화책·웹툰·PDF 멀티플랫폼 뷰어 **TapTap**의 배포용 저장소.
React Native + TypeScript로 한 벌을 쓰고, 플랫폼마다 다른 것만 확장자로 가른다.

> **아직 배포된 릴리스가 없다.** 아래는 릴리스 노트가 아니라 **배포 전 개발 기록**이다.
> 첫 릴리스가 나오면 이 문서 위에 릴리스 노트가 쌓인다.

| | |
|---|---|
| 지원 예정 | Android · iOS/iPadOS · Windows · macOS |
| 지금 동작하는 것 | **Android 실기기.** 나머지 셋은 코드는 있으나 아직 한 번도 빌드된 적이 없다 |
| 읽는 형식 | `cbz`·`zip` (본체) · `pdf` / `cbr`·`epub`·`txt`는 아직 |
| 개발 순서 | Android → iOS → Windows → macOS |

앱은 **PC에서 USB로 복사해 넣은 파일을 읽는 것**을 주 사용 방식으로 설계했다.
그래서 저장 경로는 반드시 탐색기·Finder·MTP로 접근 가능한 위치여야 한다.

## 개발일지

### 2026-08-15
- **FTP · FTPS** — 온라인 탭에 붙는 프로토콜이 다 찼다 (Google Drive · SFTP · SMB · FTP)
- TLS와 파일명 인코딩을 계정마다 고른다 — 한글 이름이 깨져 보이면 EUC-KR로
- 접속 정보를 고치면 바로 반영된다. 전에는 앱을 껐다 켜야 했다

### 2026-08-14
- **온라인 탭** — 접속 정보를 등록해 서버를 훑고 서재로 받는다 (Google Drive · SFTP · SMB)
- 폴더째 받기 — 담을 때 파일 단위로 펴서, 하나가 실패해도 그것만 다시 받는다
- 여러 폴더·파일을 한 번에 (길게 눌러 선택 모드)
- 받는 동안 화면이 안 꺼진다
- 같은 파일이 있으면 어떻게 할지 옵션에 (건너뛰기·덮어쓰기·둘 다 두기)
  — 건너뛰기면 끊긴 다운로드를 다시 걸었을 때 이어받은 것처럼 된다
- 받기 현황 — 우측 하단에 떠 있는 단추, 테두리가 전체 진행률을 그린다
- 누르면 팝업으로 열려 묶음별 진행률을 보여 주고, 펼치면 파일이 하나씩
- 계정 목록 편집 — 길게 눌러 들어가서 순서를 끌어 옮기고, 접속 정보를 고치고, 지운다
- 목록에서 표지 없는 폴더는 칠을 뒤집어 그린다 (온라인처럼 폴더·파일이 섞이면 안 갈렸다)
- 뷰어에서 상단 상태바가 툴바와 같이 뜨고 진다 (읽는 동안은 몰입, 그림은 안 밀린다)
- 뷰어 밝기를 앱 전용/기기 전체 중에 고를 수 있게 (밝기 아이콘을 눌러 전환)
- 자동 밝기일 때는 슬라이더가 잠기고, 값만 조도를 따라 움직인다
- 앱 아이콘 — 흘림체 `tt` (어댑티브·모노크롬·레거시 세 벌, 배경은 그라디언트 XML)
- 앱 안의 강조색을 파랑에서 아이콘과 같은 주황으로 (뷰어 툴바에 남아 있던 파란색도)
- 끝까지 본 책은 책갈피 목록에 안 쌓인다 (기록은 남아서 앞쪽으로 돌아가면 다시 나타난다)
- 보기 방식 아이콘이 '지금 상태'가 아니라 '누르면 될 상태'를 가리키게 (3단 순환이라 지금을 봐도 다음이 안 보였다)
- 스와이프 삭제 손맛 정리 — 빨간 판이 밀린 만큼 자라고 아이콘이 그 중앙을 따라간다
- 판 크기(72dp)를 넘겨야 삭제, 넘어가면 고무줄 저항
- 오버스와이프 때 판과 행 사이에 검은 틈이 생기던 것 수정
- 판 투명도를 나온 비율에 맞춤 (100% 넘으면 1.0 고정)
- 페이지 숫자가 스크롤바에 붙어 답답하던 것 — 오른쪽 여백 추가

### 2026-08-13
- 책갈피를 시리즈(부모 폴더)로 묶기 — 접기, 접힌 상태 기억, 옵션에서 끄기
- 목록 행을 왼쪽으로 밀어 삭제 (책갈피·즐겨찾기), 휴지통·하트 버튼 제거
- 책갈피 행 오른쪽에 읽던 자리 표시 (`12 / 200`)
- 개별 삭제도 확인창을 띄우고, 삭제 관련 문구를 `삭제`로 통일
- 옵션 > 툴바 구성 — 밝기·페이지 슬라이더·웹툰 폭·자동 스크롤 속도를 하나씩 끄기
- 권 이동 버튼은 확인 없이 바로 이동, 항상 표시
- 긴 파일명을 `앞 ⋯ 뒤`로 줄이고 확장자를 뗌 (권수가 잘려 나가던 것)
- 웹툰 행 경계마다 생기던 1px 검은 실선 수정
- 확대 중 대각선 팬 — 두 축이 한 프레임에 정해진다
- 확대 중 관성·가장자리 늘어남·회차 이동
- 스와이프로 하는 권 이동이 하루 동안 죽어 있던 것 수정
- 뷰어 툴바 줄맞춤 — 모든 줄이 `[선두 44][가운데][후미 44]`
- 자동 스크롤 속도를 7단계 25~175%로, 가감속 추가
- 확대하면 회차 처음·끝에서 화면이 두 배로 빨리 움직이던 것 수정

### 2026-08-12
- 웹툰 확대 — 레이아웃이 아니라 transform으로 (핀치·더블탭·가로 팬)
- 확대 중 오버스와이프를 미는 대신 늘이는 방식으로
- 오버스와이프 판정을 한 곳으로 모음 (축은 매개변수)
- 웹툰 폭 설정 — 가로로 긴 화면에서 화면 폭을 다 쓰지 않게
- 웹툰 폭 슬라이더를 뷰어 툴바로
- 자동 스크롤이 타일 경계에서 움찔하던 것 수정
- 좌우 탭이 가끔 이전 페이지로 가던 것 수정
- 웹뷰 전환 선택지를 따져 문서로 세움 (보류)

### 2026-08-11
- 웹툰 스크롤바 — 플랫폼 것이 안 그려져 커스텀으로
- 웹툰 자리 이동을 오른쪽 세로 슬라이더로
- 웹툰 자동 스크롤 (누르고 있는 동안), 상하 오버스와이프로 이전/다음 화
- 슬라이더로 훑을 때 검은 화면이 많던 것 — 원인은 디코딩이 아니라 해제 대기열
- 확인 대화상자를 뒤로가기·바깥 탭으로 닫을 수 있게
- 자동 스크롤이 손가락만 미끄러져도 멈추던 것

### 2026-08-10
- 긴 장을 세로로 잘라 그린다 — 안 그려지던 벽을 넘음
- 압축을 목차만 읽고 연다, 장은 볼 때 푼다 — 진입 5.2초 → 1.9초
- FastImage 제거 — 본 이미지마다 15MB를 안 놓아 native heap이 1.1GB까지 갔다
- 목록 정렬 174ms → 20ms
- 웹툰 마운트 창을 "장 수"가 아니라 "화면 수"로 고정
- 긴 장에서 나갔다 와도 그 장 맨 위로 안 돌아감
- 권을 되돌아왔을 때 검은 화면이 뜨던 것 수정

### 2026-08-09
- 뷰어 제스처를 RNGH + reanimated로 (탭·끌기·핀치)
- 더블탭 확대, 확대한 그림 끌기, 핀치 초점 보정, 가장자리 2단계 넘김
- 한 장/두 장/원본 보기
- ZIP 바이트를 JS에서 걷어내고 네이티브 스트림으로 (썸네일 장당 3~4초 → 0.6초)
- 읽던 위치를 파일 번호로 들고 있게 — 회전할 때마다 밀리던 것
- 회전 튐의 원인 넷을 차례로 잡음
- 세로 화면에서는 보기 방식 설정을 통째로 무시
- 툴바 버튼은 뜻이 없으면 사라진다는 규칙 확정

### 2026-08-08
- 뷰어 툴바 — 상하단 툴바, 중앙 탭 토글, 진입/이탈 연출
- 뷰어 밝기 조절 (Android)
- 폴더 썸네일 + 표지 사용 설정 3단계
- 아이콘을 한 표로 모으고 아이콘 테마 추가
- 터치 영역 동작·화면 회전 고정
- 저장이 겹치면 그 회차가 통째로 날아가던 것 수정

### 2026-08-07
- `src/` 전체를 JavaScript → TypeScript 전환 (4개 플랫폼 계약 포함)
- 다국어(한/영) 지원
- 옵션 화면 재설계 — 섹션·선택 시트·캡션
- 저장소를 AsyncStorage에서 스토어별 JSON 파일로
- 뷰어 좌우 터치 영역으로 페이지/권 이동, 스와이프 오버스크롤로 권 이동
- 가로모드에서 탭바가 좌측 레일로 전환
- 목록 화면 셋을 공통 컴포넌트로 묶음

### 2026-08-06
