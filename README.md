# TapTap — 배포

만화책·웹툰·PDF 멀티플랫폼 뷰어 **TapTap**의 배포용 저장소.
React Native + TypeScript로 한 벌을 쓰고, 플랫폼마다 다른 것만 확장자로 가른다.

> **아직 배포된 릴리스가 없다.** 아래는 릴리스 노트가 아니라 **배포 전 개발 기록**이다.
> 첫 릴리스가 나오면 이 문서 위에 릴리스 노트가 쌓인다.

| | |
|---|---|
| 지원 예정 | Android · iOS/iPadOS · Windows · macOS |
| 지금 동작하는 것 | **Android 실기기.** 나머지 셋은 코드는 있으나 아직 한 번도 빌드된 적이 없다 |
| 읽는 형식 | `cbz`·`zip` (본체) · `pdf` / `cbr`·`epub`·`txt`는 아직 |
| 개발 순서 | Android → iOS → Windows → macOS |

앱은 **PC에서 USB로 복사해 넣은 파일을 읽는 것**을 주 사용 방식으로 설계했다.
그래서 저장 경로는 반드시 탐색기·Finder·MTP로 접근 가능한 위치여야 한다.

## 개발일지

### 2026-08-22
- 글 뷰어에서 **배경·글꼴을 바꿔도 읽던 자리를 지킨다.** 그 구간 처음으로 떨어지던 것을 고쳤다
- 책의 처음·끝에서 **좌우로 늘어난다** — 스크롤 모드의 상하 늘어남과 같은 규칙이 됐다
- 끌어서 넘기는 거리를 짧게(화면 폭의 30%), 이징을 만화와 같은 곡선으로
- 쪽 모드에서 위아래로 늘어나던 것과 웹뷰 기본 확대(더블탭·핀치)를 껐다 — 글에는 뜻이 없다
- 화면을 돌리면 **두 쪽/한 쪽이 따라 바뀐다**
- **EPUB이 훨씬 빨리 열린다.** 챕터를 한 번에 풀고, 본문을 훑는 방식을 바꿨다

### 2026-08-21
- **화질 보정이 동작한다.** 뿌옇게 뜬 스캔의 검정과 흰색을 그 장에 맞춰 펴 준다. 툴바에서 켜고 끄고, 잘 만든 스캔은 켜도 아무 일이 없다
- **PDF가 만화와 똑같이 열린다.** 툴바·탭으로 쪽 넘김·두 장 보기·세로 스크롤·확대·회차 이동이 전부 만화와 같다. 쓰던 PDF 라이브러리는 걷어냈다
- **확대하면 그 자리가 또렷해진다.** 손을 떼면 보고 있는 영역만 화면 해상도로 다시 그린다 — PDF는 벡터라 새로 조판되고, 스캔본은 그동안 잘려 나가던 원본 픽셀을 되찾는다
- 쪽을 준비하는 동안 **흰 종이와 표식**이 뜬다. 검은 자리만 보여서 원래 그런 건지 알 수 없던 것을 고쳤다
- PDF는 앱 설정과 무관하게 **좌철로 연다.** 문서에는 우철이 없다 — 툴바에서 바꾸면 그대로 남는다
- **PDF와 EPUB도 목록에 표지가 뜬다.** 소설만 든 폴더는 표지가 원리적으로 없어서 **글 폴더 아이콘**으로 알린다
- 스크롤 모드에서 글이 **화면 위아래 끝에서 녹아 없어진다.** 획이 뚝 끊기던 자리다
- 글꼴을 못 깔면 **글이 영영 안 열리던 것**을 고쳤다. 이제 기기 글꼴로 넘어가고, 그래도 못 그리면 8초 안에 무슨 일인지 말한다
- 앱이 백그라운드에 있는 동안 시스템이 정리해도, 돌아오면 **보던 화면 그대로**다. 최근앱에서 직접 없앤 뒤에는 첫 화면에서 시작한다
- **EPUB을 읽는다.** 삽화가 본문 사이에 그대로 들어가고, 글자 크기를 바꾸면 그림도 같이 재배치된다. 표지와 장 표지는 **여백 없이 화면을 채운다**
- 글도 **끌면 다음 쪽이 손가락을 따라온다.** 만화처럼 옆 쪽이 같이 딸려 오고, 반쯤 넘기면 넘어간다
- 쪽 넘김 연출이 둘로 갈렸다 — **밀기**는 다음 쪽이 밀고 들어오고, **흐리게**는 지금 쪽이 제자리에서 옅어지며 다음 쪽이 겹쳐 들어온다
- 글 책의 진도를 **백분율**로 적는다. 쪽 수는 글꼴·화면·회전마다 달라 목록이 알 수 없다

### 2026-08-20
- 뷰어 툴바가 **떠 있는 알약**으로 바뀌었다. 읽는 내내 쓰는 것(제목·지금 자리·조절 버튼)만 남고, 값 조절은 버튼을 눌러 카드로 펼친다 — 가로에서 본문이 다시 넓어졌다
- 카드는 **밖을 누르면 닫힌다.** 배경은 뒤가 비쳐 보이는 흐림이다
- 지금 자리가 화면 아래 가운데에 뜬다. 페이지는 `12 / 200`, 스크롤은 백분율
- 슬라이더로 옮길 때 숫자가 두 번 튀거나 엉뚱한 데 앉던 것을 고쳤다
- 글꼴·배경 고르는 판이 라이트 테마에서 안 보이던 것을 고쳤다
- 읽던 자리를 **페이지를 넘길 때마다** 저장한다. 서재와 책갈피를 다른 파일로 갈라서, 한 번 쓰는 양이 440바이트다 — 앱이 갑자기 꺼져도 자리를 안 잃는다
- 나눔명조·리디바탕을 고르면 **글이 아예 안 열리던 것**을 고쳤다. 글꼴을 본문에 실어 보내던 것이 원인이라 파일로 바꿨다
- **그 흐림은 같은 날 다시 걷어냈다.** 매 프레임 화면을 통째로 다시 그리는 방식이라, 회차 끝의 늘어나는 손맛과 슬라이더 반응, 글을 여는 것까지 잡아먹고 있었다
- 글을 못 그릴 때 **조용히 다른 방식으로 갈아타던 것**을 없앴다. 이제 무슨 일인지 알리고 다시 시도할 수 있다
- 가로 두 쪽 보기에서 왼쪽 가장자리에 지난 쪽 글자가 점점점 찍히던 것을 고쳤다

### 2026-08-19
- 쪽 슬라이더가 **찍은 자리로 한 번에** 간다. 뷰어 슬라이더를 전부 직접 그려 손가락과 어긋나지 않는다
- 화면을 여러 번 돌려도 읽던 자리가 그대로다
- 줄 간격·여백은 **놓을 때 한 번만** 조판한다. 끄는 동안은 숫자만 따라간다
- 서식(글자 크기·줄 간격)과 본문 여백 툴바를 옵션에서 끌 수 있다
- 옵션 맨 아래 버전 표시를 일곱 번 두드리면 개발자 메뉴가 나온다

### 2026-08-18
- **큰 소설이 빨리 열린다** — 2.4MB 소설이 17초에서 3.7초로. 여는 시간이 책 크기를 거의 안 따른다
- 전체 쪽 수를 뒤에서 재 두었다가 다음에 열 때 바로 쓴다. 세로·가로를 따로 기억한다
- **네오둥근모Pro**를 앱에 함께 넣었다 — 어느 기기에서나 같은 글꼴
- 텍스트 배경에 **파랑**(옛 도스 화면)과 **남색**(옛 이지뷰어)을 더했다
- 쪽 넘김 모션을 고른다 — 밀기 / 흐리게 / 없음
- 가로에서 **글도 두 장 보기**
- 글 끝에서 한 번 더 밀면 늘어난다 — 만화와 같은 감
- 스크롤로 볼 때 한 권이 한 번도 안 끊긴다

### 2026-08-17
- **TXT 뷰어** — 인코딩을 알아서 알아본다(UTF-8 · CP949). 쪽 넘김과 스크롤 둘 다
- **글은 브라우저 엔진이 조판한다** — 쪽이 정확히 나뉘고, 글자 크기를 바꿔도 즉시 다시 흐른다
- 텍스트 뷰어 툴바에서 글자 크기·줄 간격·글꼴·배경·여백을 다 만진다. 글꼴과 배경은 **보고 고른다**
- 텍스트 쪽 넘김이 좌우로 넘어간다
- **압축 안 한 이미지 폴더를 한 권으로** — 이미지를 누르면 그 폴더가 책이 된다
- 이전/다음 권이 종류를 안 넘나든다. 만화 옆에 소설이 있어도 만화로만 이어진다
- **즐겨찾기** — 오른쪽으로 밀어 담고, 한 번 더 밀면 뺀다. 내 기기·계정별로 묶인다
- 즐겨찾기가 편집 중에도 묶여 있다. 순서는 묶음 안에서 바꾼다
- 사라진 즐겨찾기를 누르면 지울지 물어본다
- 오프라인에서 파일·폴더 삭제 — 길게 눌러 고르고 한 번에 지운다(옵션에서 켠다)
- 온라인에서 시작 폴더 위로도 올라간다. 즐겨찾기로 들어가면 그 폴더가 바로 열린다

### 2026-08-15
- **FTP · FTPS** — 온라인 탭에 붙는 프로토콜이 다 찼다 (Google Drive · SFTP · SMB · FTP)
- TLS와 파일명 인코딩을 계정마다 고른다 — 한글 이름이 깨져 보이면 EUC-KR로
- 접속 정보를 고치면 바로 반영된다. 전에는 앱을 껐다 켜야 했다

### 2026-08-14
- **온라인 탭** — 접속 정보를 등록해 서버를 훑고 서재로 받는다 (Google Drive · SFTP · SMB)
- 폴더째 받기 — 담을 때 파일 단위로 펴서, 하나가 실패해도 그것만 다시 받는다
- 여러 폴더·파일을 한 번에 (길게 눌러 선택 모드)
- 받는 동안 화면이 안 꺼진다
- 같은 파일이 있으면 어떻게 할지 옵션에 (건너뛰기·덮어쓰기·둘 다 두기)
  — 건너뛰기면 끊긴 다운로드를 다시 걸었을 때 이어받은 것처럼 된다
- 받기 현황 — 우측 하단에 떠 있는 단추, 테두리가 전체 진행률을 그린다
- 누르면 팝업으로 열려 묶음별 진행률을 보여 주고, 펼치면 파일이 하나씩
- 계정 목록 편집 — 길게 눌러 들어가서 순서를 끌어 옮기고, 접속 정보를 고치고, 지운다
- 목록에서 표지 없는 폴더는 칠을 뒤집어 그린다 (온라인처럼 폴더·파일이 섞이면 안 갈렸다)
- 뷰어에서 상단 상태바가 툴바와 같이 뜨고 진다 (읽는 동안은 몰입, 그림은 안 밀린다)
- 뷰어 밝기를 앱 전용/기기 전체 중에 고를 수 있게 (밝기 아이콘을 눌러 전환)
- 자동 밝기일 때는 슬라이더가 잠기고, 값만 조도를 따라 움직인다
- 앱 아이콘 — 흘림체 `tt` (어댑티브·모노크롬·레거시 세 벌, 배경은 그라디언트 XML)
- 앱 안의 강조색을 파랑에서 아이콘과 같은 주황으로 (뷰어 툴바에 남아 있던 파란색도)
- 끝까지 본 책은 책갈피 목록에 안 쌓인다 (기록은 남아서 앞쪽으로 돌아가면 다시 나타난다)
- 보기 방식 아이콘이 '지금 상태'가 아니라 '누르면 될 상태'를 가리키게 (3단 순환이라 지금을 봐도 다음이 안 보였다)
- 스와이프 삭제 손맛 정리 — 빨간 판이 밀린 만큼 자라고 아이콘이 그 중앙을 따라간다
- 판 크기(72dp)를 넘겨야 삭제, 넘어가면 고무줄 저항
- 오버스와이프 때 판과 행 사이에 검은 틈이 생기던 것 수정
- 판 투명도를 나온 비율에 맞춤 (100% 넘으면 1.0 고정)
- 페이지 숫자가 스크롤바에 붙어 답답하던 것 — 오른쪽 여백 추가

### 2026-08-13

- 목록 행을 왼쪽으로 밀어 삭제 (책갈피·즐겨찾기), 휴지통·하트 버튼 제거
